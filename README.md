VolunteerBridge
VolunteerBridge is a centralized cloud platform developed for the 2026 Google Solution Challenge. It bridges the gap between NGOs and localized volunteer "squads" in Pune using real-time data and Google Gemini AI. Solution Challenge 2026 - Prototype PPT Template.pptx.pdf: 1, 3]

🚀 The Problem
In cities like Pune, coordination during local crises—such as accidents on the NH-48 or monsoon waterlogging—is often fragmented. Existing platforms lack real-time synchronization, making it difficult for NGOs to deploy the right help quickly. 

✨ Key Features
NGO Command Center: A real-time dashboard for NGOs to track volunteer activity, success rates, and localized need intensity. Solution Challenge 2026 - Prototype PPT Template.pptx.pdf: 28, 42]

AI Smart-Task Builder: Powered by Google Gemini, this feature automatically transforms community incident reports into structured tasks with required skills and criticality levels. Solution Challenge 2026 - Prototype PPT Template.pptx.pdf: 48, 78]

Social Value Quantifier: Our system automatically converts volunteer hours into economic impact (e.g., ₹25/hr saved), helping NGOs prove their value with data. Solution Challenge 2026 - Prototype PPT Template.pptx.pdf: 28]

Pune Heroes Squads: Specialized, location-based teams (like the Pune Heroes) that receive instant notifications for hyper-local response. Solution Challenge 2026 - Prototype PPT Template.pptx.pdf: 45, 60]

🏗️ Architecture
The app follows a cloud-native architecture where the VolunteerBridge Web App communicates directly with Firebase for data and Google AI Studio for intelligent task processing. To ensure reliability during disasters, we have implemented a Custom JS Local Scoring Algorithm as a fail-safe when the AI is offline.
